# Gavel — privacy policy

One page, hosted so that anyone can read it without signing in, which is what
Google Play asks for. It is the only thing in this repository; Gavel's source
lives elsewhere and stays private.

Published at <https://articsaber.github.io/gavel-privacy/>.

`index.html` is generated — don't hand-edit it. The policy is written in
Markdown in the app's own repository (`docs/privacy-policy.md`) and built with
`python tools/make-privacy-page.py`; copy the result here when it changes.
